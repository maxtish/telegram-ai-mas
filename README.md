# 🇩🇪 AI German Tutor (Multi-Agent System) 🤖

Проект представляет собой Telegram-бота для изучения немецкого языка с максимальным погружением. Вместо стандартного ИИ-ассистента система использует **Multi-Agent System (MAS)** — набор специализированных нейросетей, которые работают в команде, чтобы создать иллюзию общения с живым носителем языка.

У каждого пользователя свой уникальный ИИ-собеседник со своим характером, городом проживания, хобби и расписанием дня.

---

## 🏗 Архитектура Агентов

Проект разделен на несколько независимых ИИ-агентов для оптимизации стоимости API и повышения реалистичности:

1. 🎭 **ИИ-Инициализатор (Генератор Персоны)**
   * Срабатывает один раз при команде `/start`.
   * Создает уникальную личность (имя, возраст, профессию, город в Германии, хобби, стиль общения).
   * Жестко привязывает созданного персонажа к Telegram ID пользователя.

2. 📅 **ИИ-Планировщик (Сценарист)**
   * Срабатывает асинхронно 1 раз в сутки.
   * Анализирует день недели и карточку персоны, чтобы составить реалистичное расписание.
   * Создает триггеры для инициативы со стороны бота (например, бот сам пишет в 13:30, что пошел на обед и ест Currywurst).

3. 👩‍🏫 **ИИ-Учитель (Аналитик)**
   * Работает в фоне (не общается с пользователем напрямую).
   * Читает историю переписки, анализирует грамматические ошибки (падежи, порядок слов, предлоги).
   * Формирует скрытые педагогические задачи для Коммуникатора на следующий день (например: "спровоцируй пользователя на использование Dativ").

4. 💬 **ИИ-Коммуникатор (Собеседник)**
   * Главный агент, общающийся с пользователем в реальном времени.
   * Учитывает контекст: карточку персоны, текущую задачу от Планировщика, рекомендации от Учителя и историю диалога.

## 🛠 Технологический стек

* **Backend:** Node.js (v20), TypeScript
* **Telegram API:** Telegraf
* **Database:** PostgreSQL + Prisma ORM
* **Queue & Scheduler:** BullMQ + Redis
* **AI Integration:** OpenAI API SDK (GPT-4o-mini / GPT-4o)
* **Server:** Hetzner Cloud (Ubuntu 24.04 LTS)

## 📂 Структура проекта

```text
src/
├── agents/             # Логика ИИ-агентов
│   ├── persona.ts      # Генерация уникального собеседника
│   ├── planner.ts      # Создание расписания дня
│   ├── teacher.ts      # Анализ грамматики и словарного запаса
│   └── communicator.ts # Ведение диалога в реальном времени
├── bot/                # Инициализация Telegraf и middleware
├── database/           # Инстанс Prisma Client
├── express/            # Веб-сервер (для вебхуков или API)
├── workers/            # Воркеры BullMQ для фоновых задач
│   ├── scheduler.ts    # Обработчик расписания
│   └── media.ts        # Генерация TTS и изображений
├── index.ts            # Точка входа в приложение
└── config.ts           # Валидация переменных окружения
```
